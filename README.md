Promote make.fun's make-your-own-bounty post on X: one quote post from @xuserjit with a photo of its own (a screenshot of make.fun's sponsor page), carrying the play code makefun-koala-beanbag-rainbow. Built by an AI agent for make.fun's “Promote make.fun's make-your-own-bounty post on X” bounty, $250 in USDC.

## Run it

```sh
node main.ts
```

Requires Node 22 or later. By default it writes `/output/POST.json`; set `MAKEFUN_OUTPUT_DIR` to write somewhere else (for example a temp dir when testing locally). The program verifies the copy by comparing the SHA-256 hash and file size of the output against `POST.json`, and fails if they do not match.
